# ⚡ Quantum Suite: Photometric Light Analyzer & QuantumType Engine

A modern, web-based dual-utility dashboard designed with a futuristic dark-mode glassmorphism UI. Built using modern HTML5, CSS3, and Vanilla JavaScript with zero external dependencies.

🔗 **Repository Link**: [https://github.com/ZoyaSaqib/ZS-Quantum-Lumina](https://github.com/ZoyaSaqib/ZS-Quantum-Lumina)

---

## 🌟 Key Features

### 1. 💡 Quantum Lumina Pro — Photometric & Ergonomic Light Analyzer
* **Live Luminance Index**: Uses browser camera access to measure real-time environment light intensity (0–100%).
* **Laptop Ergonomics Suitability Matrix**: Automatically evaluates ambient conditions to determine if lighting is optimal for laptop screen work, too dim (preventing eye strain), or overly bright (preventing screen glare).
* **Photometric Telemetry**:
  * Real-time Lux Equivalent & Footcandle (FC) calculations.
  * Correlated Color Temperature (CCT) in Kelvin.
  * Blue Light Hazard Indicator.
* **Live Visual Spectrum**:
  * RGB Spectral Decomposition (Red, Green, Blue channel breakdown).
  * Real-time Luminance Spectrum Histogram rendered on HTML5 Canvas.
* **Interactive Control Matrix**: Switch between front/rear cameras, freeze frame buffer, and log/export telemetry data.

---

### 2. ⌨️ QuantumType Core — Precision Typing Speed Test
* **Real-time WPM Metrics**: Calculates Words Per Minute (WPM) dynamically as you type.
* **Precision Tracking**: Monitors live Accuracy (%) and tracks typing errors.
* **Custom Time Intervals**: Choose between 15s, 30s, or 60s test durations.
* **Live Visual Character Feedback**: Highlights correctly typed characters in green, mistakes in red, with an animated cursor guide.
* **Results Performance Modal**: Generates a final score card summarizing WPM, Accuracy percentage, and total error count.
